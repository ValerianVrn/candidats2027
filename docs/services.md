# External services and accounts

Every platform the site depends on: what it does, where it is wired, what it costs and how to stop it. **No
secrets here**: the repo is public. Only names and ids that are already public (in the site's HTML or the repo).
Passwords, tokens and account e-mails stay in the owner's password manager.

Rule: when a service, an account or a build variable is added or removed, update this file in the same PR.

Columns marked « owner » are for what only the owner knows (renewal dates, billing).
